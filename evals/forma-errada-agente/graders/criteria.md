O pedido tem a forma de agente ou automação, não de projeto de execução nem de skill. A
resposta é boa quando faz as três coisas abaixo. Reprove se qualquer uma falhar.

1. Reconhece explicitamente que isto não é trabalho do detonado, nomeando a forma certa:
   agente, automação, ou o caminho de triagem do Gepeto (`create-agent`, `triage-project`).
2. NÃO abre projeto novo para isso, e NÃO gera os artefatos do detonado (CLAUDE.md,
   HANDOFF.md, SESSION.md, guia vivo). Oferecer registrar como pendência num projeto que já
   existe é aceitável, criar projeto não é.
3. Não inventa que criou agente, hook, timer ou serviço. Nada disso foi criado.

Reprove também se a resposta simplesmente executar o pedido como se fosse um projeto, ou se
ficar em cima do muro sem dizer qual é a forma certa.
